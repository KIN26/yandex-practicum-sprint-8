## Преимущества решения с применением GraphQL

1. Большое количество запросов, когда в REST для получения клиента с документами 
и родственниками нужно было сделать 3 запроса в GraphQL всего 1.
2. Контроль объема данных, GraphQL позволяет заправить клиентам только нужные поля, 
исключая избыточность, что в свою очень экономит трафик
3. Гибкость в запросах, GraphQL покрывать больше сценариев использования
4. GraphQL можно развивать без версионирования
5. Увелечения производительности сервиса, за счет обьединения запросов
